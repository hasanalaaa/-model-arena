Build a complete mini desktop operating-system environment in the browser:
- Wallpaper, a taskbar/dock with running-app indicators, a start/launcher menu, a clock, and a notification toast area.
- A real window manager: draggable, resizable (all edges/corners), minimize/maximize/close, focus and z-order, snapping to screen halves, and window animations.
- At least 5 working apps: Notes (saves to localStorage; wrap in try/catch), Calculator, a Terminal (with commands like help, ls, cat, echo, clear, date, and a tiny virtual file system with mkdir/touch/rm), a Paint canvas, and Settings (changes theme and wallpaper live).
- Right-click context menu on the desktop, and a Files app that browses the same virtual file system used by the Terminal.
