# Shared rules (appended to every test, identical for every model)

You are being evaluated on a visual, interactive output. Follow these rules exactly:

1. Output **one single, complete, self-contained HTML file** (HTML + CSS + JavaScript inline). Reply with the code only, no explanation.
2. It must run by simply opening the file in a modern desktop browser (Chrome). No build step, no server, no external assets: no images, no web fonts, no external CSS or JS files.
3. The only exception: if the task explicitly says a library is allowed, load exactly that library from the given URL and nothing else.
4. Everything must work on first load without any user action: animations start by themselves, and the page must have no console errors.
5. The page should fill the whole browser viewport and handle window resizing.
6. Take your time and aim for the best result you can produce. This is a single attempt: there will be no follow-up and no fixes.
